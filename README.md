# AI Interview Coach

## Overview

AI Interview Coach is an AI-powered interview preparation system that generates resume-based interview questions, analyzes candidate responses, tracks eye contact and attention, and provides AI-generated feedback with detailed reports.

## Features

* Resume Parsing
* Resume-Based Question Generation
* Speech-to-Text Conversion
* Eye Contact Tracking
* Attention Analysis
* Filler Word Detection
* AI Feedback using Gemini
* Readiness Score Calculation
* PDF Report Generation
* JSON Report Generation

## Technologies Used

* Python
* OpenCV
* MediaPipe
* Whisper
* Google Gemini AI
* ReportLab

## Workflow

Resume Upload
→ Resume Parsing
→ Question Generation
→ Interview Session
→ Speech & Camera Analysis
→ AI Feedback
→ PDF/JSON Report Generation

## How to Run

1. Install dependencies

pip install -r requirements.txt

2. Create a `.env` file

GEMINI_API_KEY=YOUR_API_KEY

3. Run the project

python main.py
